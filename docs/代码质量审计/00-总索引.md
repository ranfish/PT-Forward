## 状态定义

| 状态 | 含义 |
|---|---|
| 待精读 | 已识别方向，尚未做定点精读 |
| 精读中 | 正在抽查代码与证据 |
| 已精读 | 已形成结论文档，待评审或待整改 |
| 整改中 | 已进入实现/拆分/修复 |
| 已完成 | 建议项已落地并验证 |
| 暂缓 | 已评估，当前不处理 |
