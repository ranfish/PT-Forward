## 三、标题词形规范共性（R12 依据）

- `4K → 2160p`（青蛙报错要求/织梦报错/猫站春日识别归一）
- 分辨率小写 `p`（`(480|720|1080|2160|4320)P` 违规——织梦/青蛙）
- `AC3 → DD`（青蛙）；`HDR10 → HDR`（青蛙/猫站归一）
- 编码词形按媒介分形（青蛙最细：WEB-DL 用 H.265/HDTV 用 H265/Encode 官种 x265）——v1.05 重组 title_form 已按规范，R12 做重组异常防御
- 词序（青蛙）：季集<年份前/分辨率<媒介前/片源<编码前/编码<音频前/HDR<编码前/Atmos<声道后——v1.05 重组已保证词序
