# PT-Forward 日志规范

## 日志级别使用指南

| 级别 | 使用场景 | 禁止 |
|------|---------|------|
| **Error** | 不可恢复的错误，需人工介入。自动带 stacktrace | 正常关闭(context.Canceled)、预期错误 |
| **Warn** | 异常但可继续运行，需关注 | 正常业务流程 |
| **Info** | 关键业务节点（引擎启动/删种/推送/RSS 完成） | 循环内逐条记录、正常重复事件 |
| **Debug** | 开发调试信息，生产默认关闭 | 作为唯一日志级别 |

## 结构化字段规范

### Component 字段（必填）

每个引擎/模块在 `New*()` 时通过 `logger.With(zap.String("component", "xxx"))` 标注：

| component 值 | 模块 |
|--------------|------|
| `seeding` | 刷流引擎 |
| `rss` | RSS 引擎 |
| `reseed` | 辅种引擎 |
| `publish` | 发布管线 |
| `http` | HTTP 请求中间件 |
| `stats` | 统计聚合 |
| `metadata` | 元数据抓取 |

### 常用业务字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `client_id` | string | 下载器名 |
| `info_hash` | string | 种子哈希（截取前 12 位展示） |
| `site_name` | string | 站点名 |
| `torrent_id` | string | 种子 ID |
| `rule_alias` | string | 删种规则别名 |
| `count` | int | 数量 |
| `request_id` | string | 请求追踪 ID（8 位 UUID） |
| `cost_ms` | int64 | 耗时毫秒 |

### msg 命名规范

- 统一英文，小写，冒号分隔上下文
- 格式：`context: action description`
- 示例：`syncStale: marking record as deleted`、`executeRuleDelete: torrent deleted by rule`

## 日志文件

| 文件 | 说明 |
|------|------|
| `pt-forward-YYYY-MM-DD.log` | 全级别日志（主文件） |
| `pt-forward-error-YYYY-MM-DD.log` | Error 级别独立文件 |

## 日志 API

- `GET /api/v1/system/logs?limit=&level=` 读取日志
- `DELETE /api/v1/system/logs` 清空日志
